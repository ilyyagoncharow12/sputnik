========================================================
1. ЧТО УЖЕ РЕАЛИЗОВАНО
========================================================

Личные чаты
  - 1-на-1 диалог, сам-чат "Избранное" (сохранённые файлы/медиа)
  - Редактирование, удаление, пересылка, ответы, emoji-реакции
  - История редактирования сообщения («было → стало», кто и когда правил)
  - Индикатор набора текста (typing), счётчики непрочитанных
  - Поиск сообщений внутри чата

Группы
  - Создание (пошаговый мастер) / вступление / выход / удаление
  - Поиск групп и витрина: публичная — вступление сразу,
    приватная — заявка владельцу (одобрение/отклонение в инфо группы)
  - Роли: создатель (owner), админ (admin), участник (member)
  - Права по ролям: отправка сообщений/медиа, добавление участников,
    закрепление, изменение данных, удаление сообщений, бан
  - Управление участниками и их ролями

Каналы
  - Создание (пошаговый мастер) / подписка / отписка / удаление
  - Канальные админы с детальными правами (постить/редактировать/
    удалять/добавлять админов)
  - Публичные/приватные; приватные — только по инвайт-ссылке

Сообщения и медиа
  - Текст, фото, видео, аудио, документы
  - Скачивание файлов, добавление аудио в личный плейлист

Звонки (WebRTC)
  - Аудио/видео вызовы, входящий звонок с оверлеем
  - Отключение микрофона/камеры, громкость
  - Демонстрация экрана
  - Групповые видеозвонки (кнопка)
  - История звонков

Сторис
  - Загрузка фото/видео с музыкой и подписью
  - Приватность (все / выбранные)
  - Просмотр с прогресс-баром, навигацией, лайками/реакциями/ответами
  - Статистика просмотров/лайков/реакций
  - Авто-удаление через 24 часа

Музыка (плейлист)
  - Личный плейлист, добавление/удаление треков
  - Добавление аудио из сообщений

Организация
  - Контакты (добавление/удаление/переименование)
  - Закреплённые (pinned) чаты
  - Папки чатов (folders)
  - Глобальный поиск (пользователи/группы/каналы), недавние запросы
  - Блокировка пользователей + список заблокированных

Аутентификация и аккаунты
  - Вход по телефону/паролю ИЛИ по 5-значному коду
  - Многошаговая регистрация (телефон/пароль -> имя/username -> аватар)
  - "Запомнить меня", сессии-устройства (просмотр/завершение)
  - Привязка нескольких аккаунтов и переключение между ними
  - Системный чат @sputnik (приветствие, коды входа, уведомления)

Настройки внешнего вида
  - Тема, размер шрифта, тип шрифта, радиус пузырей
  - Цвета сообщений, обои (картинка/цвет), баннер профиля
  - Настройки приватности (last seen, фото, кто может писать/
    пересылать/звонить)

Новое в v0.58.0 (признаки Telegram)
  Форматирование текста
    - Жирный, курсив, подчёркивание, зачёркнутый, код, спойлер, цитата,
      моноширинный весь текст — панель появляется при выделении текста
    - Ссылки превращаются в кликабельные автоматически
    - Поддерживаются **жирный**, ~~зачёркнутый~~, `код` вручную
  Кружки и альбомы
    - Видеокружки 1–60 сек (запись с камеры, отправка кругом)
    - Альбомы: несколько фото/видео одним сообщением, сетка по числу файлов
    - Просмотрщик альбома с листанием и перестановкой файлов
  Стикеры
    - Свои стикеры из картинок, редактор с обрезкой и эмодзи
    - Добавление стикера из сообщения, избранное, отправка стикером
  Отложенные сообщения
    - Быстрые интервалы (30 мин / 1 ч / 6 ч / завтра / неделя) или своя дата
    - Список отложенных: «Отправить сейчас» и удаление
  Блокировка приложения
    - PIN-код от 4 цифр, подсказка, автоблокировка по бездействию
  Облачный пароль (2FA)
    - Второй пароль при входе, подсказка, восстановление по email
  Premium
    - Статус, активация по промокоду, свой значок-эмодзи, выгрузка данных
    - Звёздочка рядом с именем пользователя
  Импорт контактов
    - Файл .vcf, контакты из телефона (Contacts API) или вручную

Прочее
  - PWA (manifest, иконки), адаптивность мобильный/десктоп
  - Обучение (onboarding), политика конфиденциальности, условия

- Пароли переведены с sha256 (быстро, без соли) на bcrypt (соль + медленный
  хэш). Старые аккаунты автоматически мигрируют при следующем входе:
  verify_user проверяет bcrypt, затем старый sha256 и перезаписывает хэш.
  Файл: database.py (hash_password, verify_password, verify_user).
- Настройки вынесены в .env (SECRET_KEY, DB_*): читаются через config.py
  (окружение ОС → .env → дефолт). Созданы .env и .env.example.
- SECRET_KEY больше не захардкожен в коде (main.py берёт его из .env).
- CSRF-защита: все не-GET запросы к API требуют заголовок X-CSRF-Token.
  Токен выдаётся в session и вставляется в <meta name="csrf-token"> шаблонов
  (chat.html, auth.html, call_interface.html); на фронтенде обёртка window.fetch
  автоматически добавляет заголовок. Socket.IO и /static исключены.
  Файлы: main.py, templates/chat.html, templates/auth.html,
  templates/call_interface.html.
- Rate-limit по IP (в памяти): /auth — 30 в минуту, /api/auth/send_login_code — 5
  в минуту, /api/send_message — 40 в минуту. При превышении — 429. main.py.
- CORS осознанно не сужен: приложение работает в локальной сети с разных
  устройств (разные Origin), аутентификация через SameSite cookie.
- Собран requirements.txt (Flask, Flask-SocketIO, psycopg2-binary, Pillow, bcrypt)
  для переносимости на другие машины/флешку.
