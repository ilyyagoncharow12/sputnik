=======================================================
ЧАСТЬ 1. КОМПЬЮТЕР (Windows / Linux / macOS)
=======================================================

1. ЗАПУСК
-------------------------------------------------------
Нужны Python 3.10+ и все библиотеки из requirements.txt.

  python main.py

Сервер поднимется на http://localhost:5000 и сам перезапустится, когда вы
правите файлы проекта (debug=True). Страницу в браузере после правок
перезагружайте сами (Ctrl+F5, чтобы не кэш).

В консоли будет напечатан сетевой адрес вида http://192.168.x.x:5000 —
по нему зайти можно с другого устройства в той же сети.

1.1. Если телефон не подключается (для звонков нужен HTTPS)
  Браузеры разрешают доступ к камере/микрофону только по HTTPS (кроме
  localhost). Поэтому для звонков с телефона:
    1) положить в папку certs/ файлы fullchain.pem и privkey.pem.
       Для проверки на своём комьютере можно самоподписанным сертификатом:
         mkdir certs
         openssl req -x509 -newkey rsa:2048 -keyout certs/privkey.pem -out certs/fullchain.pem -days 825 -nodes -subj "/CN=localhost"
       (для постоянного домена лучше нормальный сертификат, например
       Let's Encrypt — иначе браузер предупредит о «небезопасном» вводе)
    2) в .env задать:
         USE_HTTPS=1
         HTTPS_PORT=5443
    3) сервер сам поднимет HTTPS рядом с обычным портом.
  Без этого текст, фото, альбомы, стикеры, кружки и отложенные сообщения
  работают как обычно — нужен только интернет-браузер.

1.2. Перенос на флешке
  Весь проект переносится целиком. Обязательно должны уехать с ним:
  sputnik.db (база), .env (настройки), CHANGELOG.txt, AGENTS.md.
  Путь к базе задаётся в .env переменной SQLITE_PATH.

2. ВХОД И АККАУНТЫ
-------------------------------------------------------
2.1. Вход по паролю
  Открыть http://localhost:5000/auth, вкладка «Вход».
  Ввести телефон и пароль, принять соглашение, [Войти].

2.2. Вход по коду (без пароля)
  Вкладка входа → переключатель «По коду» → ввести телефон →
  код придёт в системный чат @sputnik → вставить его в поле кода.

  Если у аккаунта включён облачный пароль (см. 2.4), после кода
  спросят облачный пароль. Вводить нужно ИМЕННО облачный, а не обычный.

2.3. Несколько аккаунтов
  Меню (бургер) → Аккаунты → добавить вход по коду.
  Если у добавляемого аккаунта включён облачный пароль, спросят его
  сразу. Текущая сессия при этом НЕ меняется.

2.4. Облачный пароль (2FA) — включить
  Меню (бургер) → Конфиденциальность → «Облачный пароль».
  Ввести новый пароль дважды, по желанию подсказку и email для
  восстановления. Далее пароль спрашивают при каждом входе.

  Если пароль забыт: на экране входа есть «Забыли пароль?» — понадобится
  код входа, выданный в @sputnik, и email восстановления.

3. НОВЫЕ ВОЗМОЖНОСТИ v0.58.0 — КАК ПОЛЬЗОВАТЬСЯ
-------------------------------------------------------
3.1. Форматирование текста
  Выделить кусок текста в поле ввода → над полем появится панель → выбрать
  стиль. Панель пропадает, когда выделение снято.
    [Жирный] [Курсив] [Подчёркивание] [Зачёркнутый] [Код] [Спойлер]
    [Ссылка] [Весь текст моно] [×]
  Спойлер — текст под ним, клик открывает.
  Ссылка — спросит адрес, можно вставить свой текст вместо адреса.
  Можно и руками: **жирный**, ~~зачёркнутый~~, `код`, а также теги
  <i>курсив</i>, <u>подчёркивание</u>, <s>зачёркнутый</s>,
  <spoiler>спойлер</spoiler>, <quote>цитата</quote>,
  <monoall>весь текст моноширинным</monoall>.
  Одиночная звёздочка *курсив* НЕ разбирается намеренно, иначе «2*3*4»
  превратилось бы в курсив. Для курсива — панель или тег <i>.
  Ссылка, вставленная без всяких тегов, сама станет кликабельной.

3.2. Альбомы
  Выделить сразу несколько фото или видео при отправке → уйдут одним
  сообщением-сеткой (2-10 штук). Подпись пишется один раз внизу.
  Тап по сетке — просмотрщик: листается стрелками/свайпом, счётчик
  «2 / 5» сверху. Кнопка в правом верху — режим перестановки файлов,
  стрелками двигаем, [Сохранить] — порядок записывается на сервер.

3.3. Видеокружки
  Скрепка (скрепка в композере) → [Кружок] → запись 1–60 секунд кругом.
  Можно перевернуть камеру [↺] и отменить. Отправка — как у обычного
  видео. Если в поле уже есть текст, он уйдёт подписью к кружку.

3.4. Стикеры
  Панель эмодзи (кнопка смайлика) → вкладки:
    [Эмодзи] [Избранные] [Стикеры] [Создать]
  Создать: [Создать] → загрузить картинку → кадрировать (тянуть
  изображение и зум), можно наклеить эмодзи, внизу [Сохранить в
  избранное] / [Сохранить]. Эмодзи вписываются в саму картинку.
  Добавить стикер из чужого сообщения: правая кнопка на картинке в чате
  ▸ «В мои стикеры».
  Отправка стикера — тап по нему в панели.

3.5. Отложенные сообщения
  Написать текст → иконка часов в композере (рядом со скрепкой) →
  [30 минут] [1 час] [6 часов] [Завтра] [Неделя] или своя дата →
  [Отложить]. В поле ввода появится полоска «Отправится сегодня в
  16:02» с крестиком для отмены. Дальше [Отправить] как обычно.
  Список отложенных открывается из этого же окна отложки — пункт
  «Список отложенных (N)» внизу: там [Отправить сейчас] или [Удалить].
  «Отправить сейчас» доставляет сообщение немедленно, время в списке
  после этого исчезает.

3.6. Блокировка приложения (PIN-код)
  Меню (бургер) → Конфиденциальность → «Блокировка приложения».
  Задать код (4 цифры или больше), подсказку и таймер автоблокировки
  по бездействию (в т.ч. «сразу при запуске»).
  После срабатывания — экран с цифровой клавиатурой: ввести код,
  стереть [⌫], снять все [×]. Снять саму блокировку — там же в настройках,
  по вводу кода.

3.7. Premium
  Меню (бургер) → внизу пункт Premium со значком.
  Показать промокод админу → [Активировать]. Дальше:
    [Значок] — выбрать свою эмодзи-звёздочку;
    [Выгрузить данные] — файл со всеми своими данными;
  Активный Premium показывается звёздочкой рядом с именем.

3.8. Импорт контактов
  Меню (бургер) → Контакты, внизу [Импорт].
    [Файл .vcf] — выбрать файл с телефона;
    [Из телефона] — разрешить доступ (Chrome/Edge умеют);
    [Вручную] — добавить по одному.
  После импорта показывается, кого из контактов уже есть в Спутнике.

4. ГОРЯЧИЕ КЛАВИШИ И МЫШЬ
-------------------------------------------------------
  Enter                 отправить
  Shift+Enter            новая строка
  ПКМ по сообщению       контекстное меню (реакции, ответить, удалить…)
  Ctrl+C / Ctrl+V        копировать / вставить (вставка картинки из
                         буфера тоже работает)
  Esc                    закрыть просмотрщик альбома, кружок, панель
                         отложенных, модальные окна

5. ЕСЛИ ЧТО-ТО НЕ РАБОТАЕТ
-------------------------------------------------------
  Сообщения не отправляются     F12 → Console, смотрите ошибку; в
                                консоли сервера — [send_message]
  Кружки/камера не работают     нужен HTTPS (1.1) и разрешение браузера
  Код из @sputnik не приходит   код также показывается в самом чате
                                @sputnik; проверьте, что время сервера
                                верное
  «Не удалось отправить» при    проверьте свободное место на диске и
  загрузке файла               права на папку uploads
  После правок в коде страница  Ctrl+F5 — браузер держит старый JS


=======================================================
ЧАСТЬ 2. ТЕЛЕФОН (Android / iPhone)
=======================================================

1. ПОДКЛЮЧИТЬСЯ
-------------------------------------------------------
1.1. Открыть Спутник на телефоне проще всего, добавив его на главный
     экран (PWA): в Chrome/Edge меню ▸ «На экран „Домой“». Появится
     иконка, приложение откроется без адресной строки.

1.2. Адрес. В консоли сервера при запуске печатается сетевой адрес
     вида http://192.168.x.x:5000 — вводим его в браузере телефона.
     Телефон и компьютер должны быть в одной Wi-Fi сети.

1.3. Для звонков нужен HTTPS (см. 1.1 в Части 1) — с http:// камера
     и микрофон в браузере телефона не включатся.

2. ВКЛАДКА «ПК» ИЛИ «ТЕЛЕФОН» ЗАЧЕМ
-------------------------------------------------------
Интерфейс сам переключается: при ширине экрана ≤768 px (или если
включён режим телефона) — боковая панель уезжает влево, чат
открывается на весь экран. В этом режиме:
  - список чатов и чат — два разных экрана, между ними свайп/кнопка «Назад»;
  - поля ввода 16px — чтобы iOS не увеличивал страницу при фокусе;
  - кнопки крупные (не меньше 40px) — попадать пальцем;
  - контекстное меню вызывается ДОЛГИМ нажатием (~0.5 с), не правой
    кнопкой (у телефона её нет);
  - свайп по сообщению влево — ответить; свайп от левого края — назад.

3. КАК ПОЛЬЗОВАТЬСЯ НОВЫМ НА ТЕЛЕФОНЕ
-------------------------------------------------------
Всё то же самое, что в Части 1, с двумя отличиями:

3.1. Форматирование. Выделить текст пальцем долгим нажатием →
     появится панель → выбрать стиль. (На некоторых Android долгое
     нажатие открывает системное «Копировать» — тогда панель появится
     после отпускания.)

3.2. Альбомы. Галерея: выбрать несколько фото сразу (обычный выбор
     нескольких), отправить — уйдут сеткой. Просмотрщик листается
     свайпом влево/вправо, счётчик «2 / 5» сверху.

3.3. Кружки. Скрепка → [Кружок]. Разрешите доступ к камере и
     микрофону при первом запросе.

3.4. Стикеры. Кнопка смайлика → вкладка [Создать] → картинка из
     галереи → [Сохранить]. Панель стикеров запоминается, второй раз
     открывается сразу. Картинку из чужого сообщения можно сохранить
     себе: ДОЛГОЕ нажатие на неё → [В мои стикеры].

3.5. Отложенные. Иконка часов в композере → выбрать интервал →
     [Отложить] → [Отправить]. Список отложенных — там же, внизу окна
     отложки: «Список отложенных (N)».

3.6. Блокировка. Меню (бургер) → Конфиденциальность → «Блокировка
     приложения». Клавиатура на экране крупная, код вводится целиком
     (4 цифры или больше) и проверяется автоматически.

3.7. Облачный пароль. Меню (бургер) → Конфиденциальность →
     «Облачный пароль». Спрашивается при каждом входе.

3.8. Импорт контактов. Меню (бургер) → Контакты → [Импорт] →
     [Из телефона] (Chrome на Android и iOS спросят разрешение) или
     [Файл .vcf].

4. ЭКОНОМИЯ ТРАФИКА И БАТАРЕИ
-------------------------------------------------------
  - Отправляйте альбомом, а не по одному файлу.
  - Кружки — до 60 секунд, это заметно меньше трафика, чем видео.
  - Сворачивайте приложение: при уходе в фон включается автоблокировка
    (если задали таймер) — не расходует сеть.
  - Фоновые загрузки при закрытом приложении: отложенные сообщения
    всё равно отправятся в срок, сервер работает сам.


=======================================================
ЧАСТЬ 3. БЫСТРЫЙ СТАРТ (5 минут)
=======================================================
 1. python main.py, открыть http://localhost:5000
 2. Войти телефоном и паролем (или кодом из @sputnik)
 3. Меню (бургер) → Конфиденциальность → задать облачный пароль
 4. Меню (бургер) → Конфиденциальность → задать PIN-код приложения
 5. Выделить текст в поле ввода → попробовать панель форматирования
 6. Отправить 2–3 фото разом → тапнуть сетку → полистать
 7. Записать кружок: скрепка → Кружок
 8. Написать сообщение → иконка часов → «Завтра» → Отправить
 9. Через минуту открыть окно отложки → «Список отложенных» →
   «Отправить сейчас»
10. Телефон: открыть http://<сетевой адрес>:5000 → добавить на
    «Домой» → проверить, что всё влезает в экран
